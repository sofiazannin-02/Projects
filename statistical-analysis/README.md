
This project analyses the Hitters dataset from the ISLR2 R package. The dataset contains information on Major League Baseball players, with the aim of studying the factors associated with players' salaries.
The project focuses on statistical modelling and on understanding the relationship between players' characteristics and salary.

Objectives:
Explore and visualise the relationships between the variables
Identify relevant predictors of player salary
Fit and compare statistical regression models
Investigate the effect of multicollinearity and model complexity
Apply ridge and lasso regression for regularisation and variable selection
Methods

The analysis includes:
Data cleaning and preparation
Exploratory data analysis
Linear regression
Model selection
Ridge regression
Lasso regression
Cross-validation
Model comparison

Tools:
R
ggplot2 for data visualisation
glmnet for ridge and lasso regression
